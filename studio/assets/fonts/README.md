# Bundled fonts

All fonts here come from the Google Fonts repository (github.com/google/fonts)
and are licensed under the SIL Open Font License 1.1 (see OFL.txt).

| File | Family |
|---|---|
| PlayfairDisplay-VF.ttf, PlayfairDisplay-Italic-VF.ttf | Playfair Display |
| CormorantGaramond-VF.ttf | Cormorant Garamond |
| Montserrat-VF.ttf | Montserrat |
| Inter-VF.ttf | Inter |
| BebasNeue-Regular.ttf | Bebas Neue |
| GreatVibes-Regular.ttf | Great Vibes |

If a file is missing the engine falls back to Windows system fonts
(see `core/pro/typography.py` FONT_FAMILIES). Any extra .ttf/.otf dropped
in this folder can be referenced by file name as a font family.
